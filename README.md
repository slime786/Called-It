# Called it. — Phase 4

A prediction-driven community for tech, markets, crypto, world affairs and gadgets. Calls are put on record, challenged for wording, opened for play-point positions, resolved against evidence and rolled into a permanent public record.

Phase 4 adds transactional play-point wallets, YES/NO pool staking, payouts/refunds, a three-flag wording challenge threshold, draft/revision workflow, quarterly-season leaderboard scoring, improved call detail state, and stricter lifecycle handling.

See `SETUP-PHASE4.md` before uploading the frontend.
